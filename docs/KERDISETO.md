# Κερδίσετο — οδηγός

Μία εφαρμογή ψηφιακής κάρτας επιβράβευσης για πολλές επιχειρήσεις. Τίποτα δεν είναι καρφωμένο σε συγκεκριμένη επιχείρηση: λογότυπο, χρώμα, εικονίδιο, δώρα, κανόνες πόντων και ομάδα ορίζονται από τον ιδιοκτήτη κάθε επιχείρησης.

## Διευθύνσεις
| Διεύθυνση | Τι είναι |
|---|---|
| `/` | Αρχική |
| `/start` | Δημιουργία επιχείρησης (μόνο αν `SELF_SIGNUP=1`) |
| `/platform` | Διαχείριση πλατφόρμας (κλειδί `PLATFORM_ADMIN_KEY`) |
| `/invite/<token>` | Αποδοχή πρόσκλησης (ιδιοκτήτης / υπεύθυνος / ταμίας) |
| `/b/<slug>` | Κάρτα πελάτη και εγγραφή |
| `/b/<slug>/team` | Σάρωση, πελάτες, στατιστικά, ομάδα, ρυθμίσεις |
| `/b/<slug>/privacy` | Απόρρητο, από τα στοιχεία της επιχείρησης |

## Ροές
1. **Νέα επιχείρηση**: ο διαχειριστής την φτιάχνει στο `/platform` και στέλνει το link ιδιοκτήτη (μίας χρήσης, 7 μέρες). Ή ο ίδιος ο ιδιοκτήτης στο `/start`.
2. **Ιδιοκτήτης**: ρυθμίσεις → λογότυπο (PNG/JPG/WebP ≤350KB), εικονίδιο, χρώμα, δώρα, κανόνες, τρόπος εγγραφής πελατών.
3. **Ομάδα**: Ομάδα → Πρόσκληση. Ταμίας μπαίνει με δικό του 6ψήφιο PIN· υπεύθυνος και ιδιοκτήτης με email + κωδικό. Οι προσκλήσεις ακυρώνονται οποτεδήποτε.
4. **Πελάτης**: ανοίγει το link/QR εγγραφής (`open`: ελεύθερο, `code`: με μυστικό κωδικό που αλλάζει, `closed`: κλειστό), παίρνει κάρτα με email και δείχνει QR στο ταμείο.
5. **Ταμείο**: σαρώνει το QR (ή γράφει τον αριθμό κάρτας), δίνει πόντους ή εξαργυρώνει δώρο. Αναίρεση: ταμίας ως 15 λεπτά, υπεύθυνος/ιδιοκτήτης πάντα.

## QR και ασφάλεια
- Το QR στην οθόνη του πελάτη ανανεώνεται κάθε 120″ (`KT:R:…`)· στο Wallet υπάρχει στατικό QR με έκδοση (`KT:S:…`)· εναλλακτικά ο αριθμός κάρτας.
- Κάθε σάρωση δίνει «εισιτήριο» 5′ που επιτρέπει μία κίνηση. Κάρτα άλλης επιχείρησης δίνει «δεν βρέθηκε».
- Όλα τα δεδομένα φιλτράρονται με `business_id`. CSRF έλεγχος Origin σε POST/PUT/PATCH/DELETE, rate limits σε PIN, σύνδεση, εγγραφές.

## Μεταβλητές (Cloudflare Pages → Settings → Variables)
| Όνομα | Σκοπός |
|---|---|
| `LOYALTY_SECRET` | Υποχρεωτικό, ≥16 χαρ. **Μην αλλάξει μετά την έναρξη** (PIN, QR, εισιτήρια) |
| `PLATFORM_ADMIN_KEY` | Κλειδί του `/platform` |
| `SELF_SIGNUP` | `1` ώστε να δουλεύει το `/start` |
| `RESEND_API_KEY`, `LOYALTY_EMAIL_FROM` | Email κωδικών σύνδεσης και προσκλήσεων |
| `LOYALTY_DEV_CODES` | `1` μόνο για δοκιμές: επιστρέφει τον κωδικό σύνδεσης στην απάντηση |
| `APPLE_*`, `GOOGLE_WALLET_*` | Προαιρετικά, για Apple/Google Wallet |

## Βάση δεδομένων
`migrations/0100_kerdiseto_reset.sql` **σβήνει όλα τα παλιά δεδομένα** και στήνει το νέο σχήμα. Εφαρμόζεται μία φορά: `wrangler d1 migrations apply cafe-orders-db --remote` (το όνομα της βάσης μένει ως έχει).

## Τοπική ανάπτυξη
```
cd frontend
npm install
npm run db:local      # εφαρμόζει τα migrations στην τοπική D1
npm run pages:dev     # Pages + Functions στο :8788
npm test              # 13 τεστ API χωρίς δίκτυο
```
Το `.dev.vars` έχει δοκιμαστικά μυστικά (`PLATFORM_ADMIN_KEY=local-platform-key`).

## Πριν το δημόσιο
Το κείμενο απορρήτου είναι γενικό πρότυπο· χρειάζεται νομικό έλεγχο (GDPR) πριν δοθεί σε πραγματικούς πελάτες.
