# BRUN — Οδηγός Ιδιοκτήτη Προϊόντος

Αυτός ο οδηγός είναι για σένα ως ιδιοκτήτη του BRUN — όχι για developer. Εξηγεί τι είναι το app, πώς λειτουργεί σε επίπεδο επιχείρησης, τι κοστίζει, τι να κάνεις όταν κάτι χαλάει, και πώς να ζητάς αλλαγές.

## Τι είναι το BRUN

Μια mobile-only web εφαρμογή παραγγελιών καφέ. Ο πελάτης βάζει στο καλάθι όσους καφέδες θέλει (μέγεθος, ζάχαρη, ποσότητα και σχόλιο για τον καθένα), διαλέγει ώρα παραλαβής (άμεσα ή σε 15 λεπτά έως 2 ώρες) και πατά «Ολοκλήρωση παραγγελίας». Τα αγαπημένα του μπαίνουν στο καλάθι με ένα πάτημα. Μετά βλέπει στην κορυφή της σελίδας πού βρίσκεται η παραγγελία του (Στάλθηκε → Ετοιμάζεται → Έτοιμο) και, αν το ενεργοποιήσει, παίρνει ειδοποίηση όταν είναι έτοιμη. Εσύ (ή όποιος διαχειρίζεται το μαγαζί) βλέπεις τις παραγγελίες live σε πραγματικό χρόνο, με notification στο κινητό σου.

Δεν γίνεται πληρωμή μέσα στην εφαρμογή — είναι εργαλείο παραγγελίας, όχι πληρωμής.

## Πού ζει το app

- **Public URL (αυτό δίνεις στους πελάτες):** https://brunathens.pages.dev
- **Διαχείριση (μόνο για σένα):** https://brunathens.pages.dev/admin. Ανοίγει κατευθείαν τη σύνδεση διαχείρισης, χωρίς όνομα πελάτη. Οι πελάτες δεν βλέπουν κουμπί προς τα εκεί.

**Βάλε τη διαχείριση στην αρχική οθόνη του κινητού:** άνοιξε το `/admin` στο Safari (iPhone) ή στο Chrome (Android) → Κοινοποίηση → «Προσθήκη στην αρχική οθόνη». Θα εμφανιστεί ξεχωριστό εικονίδιο «BRUN Admin». Άνοιξέ το από την αρχική οθόνη, συνδέσου εκεί με τον κωδικό και πάτα «Ενεργοποίηση ειδοποιήσεων». Στο iPhone η εφαρμογή της αρχικής οθόνης δεν μοιράζεται σύνδεση με το Safari, οπότε η σύνδεση γίνεται μέσα από το εικονίδιο.

## Πώς διαχειρίζεσαι τις παραγγελίες

Στην καρτέλα «Ενεργές» οι παραγγελίες είναι ταξινομημένες με βάση το πότε πρέπει να είναι έτοιμες. Οι «Άμεσα» και όσες πλησιάζουν έχουν κίτρινη γραμμή στα αριστερά. Κάθε κάρτα δείχνει κάθε προϊόν με την ποσότητά του (π.χ. «2×») και τα σχόλια.

Για κάθε παραγγελία πατάς με τη σειρά:

1. **Παραλήφθηκε**: την είδες και ξεκινάς. Ο πελάτης βλέπει «Ετοιμάζεται».
2. **Έτοιμη**: ο πελάτης βλέπει «Είναι έτοιμο» και, αν έχει ενεργοποιήσει ειδοποιήσεις, του έρχεται ειδοποίηση.
3. **Παραδόθηκε**: την πήρε. Η παραγγελία πάει στην καρτέλα «Ολοκληρωμένες».

Η «Διαγραφή» θέλει δεύτερο πάτημα («Σίγουρα;») για να μη σβηστεί κάτι κατά λάθος.
- **Πάροχος:** Cloudflare (Pages + D1 database)
- **Κώδικας:** GitHub, https://github.com/nkourouklis-dev/brunathens

## Κόστος

Τρέχει στο δωρεάν πλάνο του Cloudflare. Καλύπτει άνετα:
- ~100.000 requests/ημέρα
- ~100GB reads/ημέρα στη βάση
- Απεριόριστο bandwidth για static περιεχόμενο

Αν το μαγαζί μεγαλώσει πολύ (πολλαπλά καταστήματα, πολύ μεγάλος όγκος), θα χρειαστεί αναβάθμιση σε paid πλάνο — κάτι που θα το δούμε αν/όταν φτάσουμε εκεί, δεν χρειάζεται καμία ενέργεια τώρα.

## Πώς παίρνεις ειδοποιήσεις για νέες παραγγελίες

Μέσω Web Push notifications στον browser — πρέπει μία φορά να πατήσεις «Ενεργοποίηση ειδοποιήσεων» μέσα στο admin panel. Σε iPhone χρειάζεται πρώτα να προσθέσεις τη σελίδα στην αρχική οθόνη (Share → Add to Home Screen), αλλιώς δεν λειτουργούν οι ειδοποιήσεις — είναι απαίτηση της Apple, όχι κάτι που μπορούμε να παρακάμψουμε.

## Τι κάνεις όταν κάτι χαλάει

**Η σελίδα δεν ανοίγει καθόλου:**
Έλεγξε πρώτα αν είναι θέμα του Cloudflare γενικά (status.cloudflarestatus.com). Αν όχι, χρειάζεται developer να κοιτάξει τα deployment logs.

**Δεν έρχονται ειδοποιήσεις:**
Ξαναπάτα «Ενεργοποίηση ειδοποιήσεων» στο admin panel. Αν συνεχίσει, χρειάζεται developer.

**Ξέχασες τον κωδικό διαχείρισης (admin):**
Χρειάζεται developer για reset — δεν υπάρχει self-service "forgot password" αυτή τη στιγμή.

Για πιο τεχνικά ζητήματα (500 errors, database issues), υπάρχει αναλυτικό runbook στο `docs/OPERATIONS.md` για όποιον developer αναλάβει.

## Πώς ζητάς νέο feature ή αλλαγή

Περίγραψε τι θέλεις σε απλή γλώσσα (τι πρόβλημα λύνει, ποιος το χρησιμοποιεί, πώς μοιάζει η ιδανική εμπειρία). Δεν χρειάζεται να ξέρεις τεχνικούς όρους — αυτό είναι δουλειά του developer να το μεταφράσει σε υλοποίηση.

Πράγματα που ήδη έχουν συζητηθεί ως πιθανές μελλοντικές προσθήκες:
- Loyalty πόντοι (μετά από Χ παραγγελίες, δωρεάν καφές)
- Ώρες λειτουργίας / αυτόματο μπλοκάρισμα παραγγελιών εκτός ωραρίου
- Εκτιμώμενος χρόνος ετοιμασίας ανά παραγγελία
- QR code στο μαγαζί για γρήγορη πρόσβαση
- Στατιστικά πωλήσεων (ποιο προϊόν πουλάει περισσότερο, ποιες ώρες έχει κίνηση)

## Δεδομένα και ασφάλεια

- Οι πελάτες δεν βάζουν password — αναγνωρίζονται μέσω της συσκευής τους
- Ο κωδικός διαχείρισης (admin) είναι μυστικός και αποθηκευμένος με ασφάλεια στο Cloudflare, όχι μέσα στον κώδικα
- Δεν αποθηκεύονται στοιχεία πληρωμής πουθενά, αφού δεν υπάρχει πληρωμή μέσα στο app
- Backup της βάσης μπορεί να γίνει οποιαδήποτε στιγμή από τον developer
