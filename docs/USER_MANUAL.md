# BRUN — Οδηγός Χρήσης

## Για τον Πελάτη

### 1. Άνοιγμα εφαρμογής
Πήγαινε στο **https://brunathens.pages.dev** από το κινητό ή τον υπολογιστή.

> 💡 Σε iPhone/iPad: Πάτα **Share → Add to Home Screen** για να το έχεις σαν app.

### 2. Δημιουργία προφίλ
- Γράψε το όνομά σου στο πεδίο «Πώς να σε φωνάζουμε;»
- Πάτα **«Ξεκίνα»**

Το όνομά σου αποθηκεύεται στη συσκευή σου — δεν χρειάζεσαι password.

### 3. Παραγγελία καφέ

**Βήμα 1 — Διάλεξε καφέ:**
Πάτα πάνω στην κάρτα του καφέ που θες (Espresso, Freddo, Cappuccino κ.λπ.)

**Βήμα 2 — Φτιάξ' τον όπως θέλεις:**
- **Μέγεθος:** Μονό / Διπλό / Τετραπλό
- **Ζάχαρη:** Σκέτος / Μέτριος / Γλυκός
- **Extras:** Γάλα, σιρόπι, πάγος (προαιρετικά)

Πάτα **«Συνέχεια»**

**Βήμα 3 — Ολοκλήρωση:**
- Διάλεξε ποσότητα (1–20)
- Πρόσθεσε σχόλια (π.χ. «χωρίς καλαμάκι»)
- Δώσε όνομα για να τον ξαναβρείς (π.χ. «Το πρωινό μου»)

Πάτα:
- **«Κράτησέ τον»** → αποθηκεύεται στα αγαπημένα
- **«Παράγγειλε τώρα»** → στέλνεται στον ιδιοκτήτη

### 4. Επανάληψη αγαπημένου
Αν έχεις αποθηκεύσει αγαπημένο, θα το βλέπεις στην αρχική. Πάτα **«Παράγγειλε ξανά»** για γρήγορη παραγγελία.

### 5. Παρακολούθηση παραγγελιών
Στην ενότητα **«Οι παραγγελίες σου»** βλέπεις το status:
- **Στάλθηκε** → Μόλις την έστειλες
- **Παραλήφθηκε** → Την είδε ο ιδιοκτήτης
- **Έτοιμο** → Έτοιμη για παραλαβή

---

## Για τον Ιδιοκτήτη (Admin)

### 1. Σύνδεση
1. Άνοιξε την εφαρμογή και μπες κανονικά (γράψε το όνομά σου)
2. Πάτα **«Άνοιξε διαχείριση»** (πάνω δεξιά)
3. Στο πεδίο **«Κωδικός διαχείρισης»** βάλε τον κωδικό
4. Πάτα **«Σύνδεση»**

### 2. Ενεργοποίηση ειδοποιήσεων
Για να σου έρχονται notifications όταν μπαίνει νέα παραγγελία:

1. Μέσα στο admin panel, πάτα **«Ενεργοποίηση ειδοποιήσεων»**
2. Δώσε άδεια στον browser για notifications
3. Σε iPhone/iPad: πρέπει πρώτα να κάνεις **Add to Home Screen**

### 3. Διαχείριση παραγγελιών
Βλέπεις όλες τις ενεργές παραγγελίες με:
- Όνομα πελάτη
- Προϊόν + επιλογές (μέγεθος, ζάχαρη, extras)
- Σχόλια
- Ώρα παραγγελίας

Για κάθε παραγγελία μπορείς να:
- Πατήσεις **«Έτοιμη»** → ο πελάτης βλέπει «Έτοιμο»
- Πατήσεις **«Διαγραφή»** → αφαιρείται από τη λίστα

### 4. Έξοδος
Πάτα **«Έξοδος»** (πάνω δεξιά) για να βγεις από το admin panel.

## Συχνές Ερωτήσεις

**Δεν μου έρχονται notifications**
- Έκανες Add to Home Screen; (σε iOS είναι απαραίτητο)
- Έδωσες άδεια notifications στον browser;
- Πάτα ξανά «Ενεργοποίηση ειδοποιήσεων»

**Ξέχασα τον admin κωδικό**
- Επικοινώνησε με τον developer για reset

**Θέλω να αλλάξω όνομα**
- Πάτα **«Άλλαξε όνομα»** στην αρχική

**Η παραγγελία μου δεν εμφανίζεται**
- Έλεγξε τη σύνδεσή σου στο internet
- Ανανέωσε τη σελίδα
